# Binary dictionary - двоичный справочник

Двоичный справочник – способ представления и хранения информации путём её разделения на два взаимоисключающих состояния.


## Структура дерева и его элемента
```c++
struct bin_tree {
    struct node* root;
};

struct node {
    node_elem_t value;      // значение узла
    struct node* left;      // левый узел – следующая характеристика(объект), если value ложно
    struct node* right;     // правый узел – следующая характеристика(объект), если value истинно
    struct node* parent;    // предок – прошлая характеристика, для корня NULL
};
```

- если поля left и right равны NULL, узел является объектом
- иначе – характеристикой

## Режимы взаимодействия с пользователем
1. Просмотр двоичного справочника в формате дерева
2. Угадывание объекта
3. Добавление объекта
4. Сравнение двух объектов

Меню содержит эти команды и команду завершения программы 
*Chose command: [v]view or [f]find or [a]add or [c]compare or [e]exit* – меню

> [!NOTE]
> При неправильном вводе будет предложено ввести повторно

> [!WARNING]
> НО при вводе имени несуществующего объекта в режимах 3 и 4 произойдет выход в меню

За выбор команды отвечает функция **WaitCommand()**

Функции запускающие выбранную команд:
1. TreeDump(tree, "view", YES_VIEW);
2. FindElementInTree(tree);
3. AddObjInTree(tree);
4. CompareObjects(tree);

Также присутствует команда выхода из программы

## Сохранение и загрузка справочника

Справочник хранится в файле treesave.txt в формате скобочной последовательности вида preorder

- За сохранение отвечает функция SaveTree(&tree);
- За загрузку дерева в программу DownloadTree(&tree, SAVE_FILENAME);

Пример:
(\<grey\>(\<cat\>(\<unknown object\>()())(\<1,5\>()()))(\<big\>(<mouse>()())(\<elephant\>()())))

## Логирование и дамп
TreeDump(tree, "view", NO_VIEW);

> [!NOTE]
> Флаги NO_VIEW и YES_VIEW отвечают за открытие окна просмотра текущего состояния дерева

Логи и дамп сохраняются в файл *logg.htm*

Тип лог файла был выбран *.htm* для повышения удобства просмотра

## Необходимое ПО для дампа
Для корректной работы требуется скачать **graphviz**

> [!NOTE]
> Не забудьте изменить путь к программе *dot.exe* в макросе **GRAPHVIZ_DOT_PATH**
